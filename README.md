# 碰碰碰

微信小游戏风格的两关麻将消除项目。

## 技术栈

- 后端: Spring Boot + MyBatis + MySQL
- 前端: 微信小程序原生实现
- 部署: 微信云托管

## 运行环境

- 小程序 AppID: `wx4448b28df0b14acf`
- 数据库: `ppp`
- 默认数据库连接参数可通过环境变量覆盖:
  - `MYSQL_ADDRESS`
  - `MYSQL_USERNAME`
  - `MYSQL_PASSWORD`
  - `MYSQL_DATABASE`

## 游戏规则

- 总时长 12 分钟
- 两关:
  - 第 1 关: `4 x 4`
  - 第 2 关: `10 x 12`
- 初始关卡保证至少一组相邻同牌
- 点击相邻同牌可消除
- 有空位时可拖动并推动行/列
- 同行/列无遮挡且存在相同麻将时可消除
- 当无可消除局面出现时自动洗牌，并确保至少存在一个可消除局面

## 部署

1. 在微信云托管中创建服务
2. 关联本仓库
3. 配置数据库连接环境变量
4. 部署后，云托管会执行 `container.config.json` 中的建表 SQL

## 本地运行

```bash
mvn spring-boot:run
```
